# Brotato Co-op — 64 Skill Icon Prompts (for agy)

Paste this whole file to agy and let it generate all 64 icons. Then run ONE mask command (bottom) to
cut every icon to a transparent circle.

---

## INSTRUCTIONS FOR AGY — read fully, then generate ALL 64 icons

For EACH entry in the list below, generate ONE **256×256 PNG** and SAVE it to:

```
<repo>/mods-unpacked/tato-Synergies/assets/skills/<slug>.png
```

…where `<slug>` is the first field of the entry (e.g. `doctor` → `doctor.png`). Create the folder if needed.

**Composition (every icon):** a CIRCULAR emblem that fills the frame — the round disc artwork must touch
all four frame edges at their midpoints, with NO white ring or gap between the art and that edge. The four
corners outside the circle are throwaway filler (they get cropped to transparency later by a script), so
keep the corners a plain flat color and put nothing important there.

**Style (every icon):** bold cartoony game ability icon like the game **Brotato** — thick dark outlines,
vibrant flat colors, one clear readable central motif, simple silhouette, on a dark disc tinted toward the
entry's listed color. NO text or letters. 256×256, full color.

After saving each file, keep going until all 64 exist.

## After agy finishes — mask ALL icons to transparent circles in ONE command

```bash
# from the repo root
bun install
bun run tools/circle-mask-icons.ts mods-unpacked/tato-Synergies/assets/skills
```

This processes every `.png` in the folder (corners → transparent). Add `--radius 122` if a thin
background ring shows at the circle edge.
